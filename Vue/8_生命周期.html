🌱 Vue 生命周期

每个 Vue 实例都会经历一个完整的生命过程，在特定节点 Vue 会自动调用相应的钩子函数

🎮 交互演示

计数器: {{ count }}
🌱
beforeCreate
实例初始化之前调用
⚠️ data 和 methods 还未初始化，无法访问
用途：可以在此添加 loading 事件
✨
created
实例创建完成后调用
✅ data 和 methods 已初始化完成，可以访问和操作
用途：常用于发起 Ajax 请求获取初始数据
📋
beforeMount
挂载之前调用
📝 模板已编译完成，但尚未挂载到页面 DOM 中
用途：可以访问 data，但 $el 还不可用
🎯
mounted
挂载完成后调用
✅ Vue 实例已挂载到 DOM，可以访问和操作 DOM 元素
用途：操作 DOM、初始化第三方库（图表、地图等）
⏳
beforeUpdate
数据更新时调用，发生在虚拟 DOM 重新渲染之前
📸 此时可以访问更新前的 DOM 状态
用途：可以在更新前移除已添加的事件监听器
✅
updated
数据更新完成，DOM 也重新渲染完成后调用
📸 此时可以访问更新后的 DOM 状态
用途：执行依赖于更新后 DOM 的操作（避免修改状态）
⚡
beforeDestroy
实例销毁之前调用
✅ 实例仍然完全可用，data、methods 等都可以正常访问
用途：清除定时器、取消订阅、解绑事件等
💀
destroyed
实例销毁后调用
❌ 所有指令解绑、事件监听器移除、子实例也被销毁
用途：做最后的清理工作或发送统计信息

💡 提示：打开浏览器控制台 (F12) 查看各个生命周期钩子的触发顺序
