# Vue 知识点详解 (11-20)

## 11. Vue组件定义

**什么是组件？**
组件就是可以重复使用的一块代码。你可以把它理解为"自己定义的HTML标签"。

**怎么定义组件？**
在Vue实例的 `components` 里定义，每个组件需要一个名字和一个模板（template）。

```html
<div id="app">
    <!-- 使用组件，就像使用HTML标签一样 -->
    <box></box>
</div>

<script>
    new Vue({
        el: '#app',
        // 定义组件
        components: {
            // 组件名是 "box"
            "box": {
                // template 是组件要显示的HTML内容
                template: '<div>这是一个组件</div>'
            }
        }
    })
</script>
```

**重点**：
- 组件名用引号包起来
- template 里写组件要显示的HTML

## 12. Vue组件模板

**问题**：如果组件的HTML内容很多，全写在 template 字符串里很乱。

**解决办法**：把模板写在 `<template>` 标签里，用 id 引用。

```html
<div id="app">
    <box></box>
</div>

<!-- 在外面定义模板 -->
<template id="box-temp">
    <!-- 模板里只能有一个根元素（最外层只能有一个容器） -->
    <div>
        <div>这是一个组件</div>
        <h1>这是组件的标题</h1>
    </div>
</template>

<script>
    new Vue({
        el: '#app',
        components: {
            "box": {
                // 用 # 加 id 来引用模板
                template: '#box-temp'
            }
        }
    })
</script>
```

**重点**：
- `<template>` 标签要写在 `<div id="app">` 外面
- 模板里的HTML必须只有一个最外层容器
- 用 `#id名` 来引用模板

## 13. Vue组件事件（methods）

**组件可以有自己的方法**，写在组件的 `methods` 里。

```html
<div id="app">
    <h1 @click="clickFun">这是父组件的标题</h1>
    <box></box>
</div>

<template id="box-temp">
    <div>
        <h1 @click="clickHandle">这是子组件的标题</h1>
    </div>
</template>

<script>
    new Vue({
        el: '#app',
        // 父组件（Vue实例）的方法
        methods: {
            clickFun() {
                console.log("父组件被点击了");
            }
        },
        components: {
            "box": {
                template: "#box-temp",
                // 子组件自己的方法
                methods: {
                    clickHandle() {
                        console.log("子组件被点击了");
                    }
                }
            }
        }
    })
</script>
```

**重点**：
- 父组件和子组件的methods是分开的，互不干扰
- 子组件的方法只能在子组件的模板里用

## 14. Vue组件的data

**组件的data必须是一个函数，并且返回一个对象。**

为什么？因为每次使用组件，都会调用这个函数，生成一份独立的数据。这样每个组件实例的数据是独立的，不会互相影响。

```html
<div id="app">
    <h1>父组件的num1: {{num1}}</h1>
    <box></box>
</div>

<template id="box-temp">
    <div>
        <h1 @click="clickHandle">子组件的num2: {{num2}}</h1>
    </div>
</template>

<script>
    new Vue({
        el: '#app',
        // 根实例的data可以是对象
        data: {
            num1: 10
        },
        components: {
            "box": {
                template: "#box-temp",
                // 组件的data必须是函数，返回对象！
                data() {
                    return {
                        num2: 20
                    }
                },
                methods: {
                    clickHandle() {
                        this.num2++;
                    }
                }
            }
        }
    })
</script>
```

**重点**：
- 根Vue实例的 `data` 可以是对象
- 组件的 `data` 必须是函数，返回一个对象
- 组件的变量只能在组件自己的模板里使用

## 15. 组件传参：父传子（props）

**父组件怎么把数据传给子组件？**

1. 在子组件标签上用 `v-bind` 绑定属性
2. 子组件用 `props` 接收

```html
<div id="app">
    <!-- 父组件通过 v-bind:val 把数据传给子组件 -->
    <box v-bind:val="i"></box>
    <box v-bind:val="j"></box>
</div>

<template id="box-temp">
    <div>
        <h1 @click="addFun">{{num2}}</h1>
    </div>
</template>

<script>
    new Vue({
        el: '#app',
        data: {
            i: 10,
            j: 20
        },
        components: {
            "box": {
                template: "#box-temp",
                // 用 props 接收父组件传来的值
                props: ["val"],
                data() {
                    return {
                        // props的值不能直接改，所以另存一份
                        num2: this.val
                    }
                },
                methods: {
                    addFun() {
                        this.num2++;
                    }
                }
            }
        }
    })
</script>
```

**重点**：
- 父传子用 `v-bind:属性名="值"`
- 子组件用 `props: ["属性名"]` 接收
- props 的值不能在子组件里直接修改，要改的话先存到 data 里

## 16. 组件传参：子传父（$emit）

**子组件怎么把数据传给父组件？**

1. 子组件用 `this.$emit("事件名", 参数)` 触发事件
2. 父组件用 `v-on:事件名="方法"` 监听

```html
<div id="app">
    <!-- 父组件监听子组件触发的 child-change 事件 -->
    <box v-bind:val="i" v-on:child-change="changeFun"></box>
    <h1>当前值：{{i}}</h1>
</div>

<template id="box-temp">
    <div>
        <h1 @click="addFun">{{num2}}</h1>
    </div>
</template>

<script>
    new Vue({
        el: '#app',
        data: {
            i: 10
        },
        methods: {
            // 父组件接收子组件传来的数据
            changeFun(a, b) {
                console.log("子组件传来的数据:", a, b);
            }
        },
        components: {
            "box": {
                template: "#box-temp",
                props: ["val"],
                data() {
                    return {
                        num2: this.val
                    }
                },
                methods: {
                    addFun() {
                        this.num2++;
                        // 子组件触发自定义事件，通知父组件
                        // 参数1：事件名（用短横线命名）
                        // 参数2及以后：要传递的数据
                        this.$emit("child-change", this.num2, this.val);
                    }
                }
            }
        }
    })
</script>
```

**重点**：
- 子传父用 `this.$emit("事件名", 数据)`
- 事件名要用短横线命名（如 child-change），不能用驼峰
- 父组件用 `v-on:事件名="方法"` 来接收

## 17. 动态组件（is属性）

**is 属性可以让一个标签变成指定的组件。**

这在需要动态切换组件时很有用。

```html
<div id="app">
    <!-- 这个div会被渲染成 box2 组件 -->
    <div is="box2"></div>
    
    <!-- 也可以写成直接使用组件标签 -->
    <!-- <box1></box1> -->
    <!-- <box2></box2> -->
</div>

<template id="temp1">
    <div><h1>组件一</h1></div>
</template>

<template id="temp2">
    <div><h1>组件二</h1></div>
</template>

<script>
    new Vue({
        el: '#app',
        components: {
            "box1": {
                template: "#temp1"
            },
            "box2": {
                template: "#temp2"
            }
        }
    })
</script>
```

**动态切换示例**：
```html
<div :is="currentComponent"></div>

<script>
    new Vue({
        el: '#app',
        data: {
            currentComponent: 'box1'  // 可以改变这个值来切换组件
        },
        components: {
            "box1": { template: "#temp1" },
            "box2": { template: "#temp2" }
        }
    })
</script>
```

**重点**：
- `is="组件名"` 可以把任意标签变成组件
- 配合 `v-bind:is` 可以实现动态切换组件

## 18. Vue.set 方法

**问题**：直接给对象添加新属性，Vue检测不到，页面不会更新。

**解决**：使用 `Vue.set()` 方法。

```html
<div id="app">
    <ul>
        <li v-for="(item, key) in obj">
            {{key}}: {{item}}
        </li>
    </ul>
    <button @click="addFun">添加属性</button>
</div>

<script>
    new Vue({
        el: '#app',
        data: {
            obj: {
                name: "张三",
                age: 18
            }
        },
        methods: {
            addFun() {
                // 错误写法：直接添加，页面不更新
                // this.obj.school = "清华大学";
                
                // 正确写法：使用 Vue.set
                // 参数1：要修改的对象
                // 参数2：属性名
                // 参数3：属性值
                Vue.set(this.obj, "school", "清华大学");
            }
        }
    })
</script>
```

**重点**：
- 直接给对象添加新属性，Vue检测不到变化
- 用 `Vue.set(对象, 属性名, 值)` 来添加新属性
- 修改已有属性可以直接改，Vue能检测到

## 19. 使用Bootstrap

**Bootstrap 是一个CSS框架**，提供了很多现成的样式，可以快速搭建好看的页面。

**怎么用？**
1. 引入 Bootstrap 的 CSS 和 JS 文件
2. 给标签加上对应的 class

```html
<!DOCTYPE html>
<html>
<head>
    <!-- 引入 Bootstrap CSS -->
    <link href="https://cdn.bootcdn.net/ajax/libs/twitter-bootstrap/5.2.3/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <!-- 使用 Bootstrap 的表格样式 -->
    <table class="table table-striped">
        <thead>
            <tr class="table-primary">
                <th>#</th>
                <th>姓名</th>
                <th>年龄</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>1</td>
                <td>张三</td>
                <td>18</td>
            </tr>
        </tbody>
    </table>
    
    <!-- 使用 Bootstrap 的按钮样式 -->
    <button class="btn btn-primary">主要按钮</button>
    <button class="btn btn-success">成功按钮</button>
    <button class="btn btn-danger">危险按钮</button>
    
    <!-- 引入 Bootstrap JS -->
    <script src="https://cdn.bootcdn.net/ajax/libs/twitter-bootstrap/5.2.3/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

**常用样式**：
- `table` - 基础表格
- `table-striped` - 条纹表格
- `btn btn-primary` - 蓝色按钮
- `btn btn-danger` - 红色按钮
- `btn btn-success` - 绿色按钮

## 20. Vue中使用checkbox

**用 v-bind 绑定 checkbox 的选中状态。**

```html
<div id="app">
    <!-- :checked 是 v-bind:checked 的缩写 -->
    <!-- 当 checked 为 true 时，复选框被选中 -->
    <input type="checkbox" :checked="checked">
</div>

<script>
    new Vue({
        el: '#app',
        data: {
            checked: true  // true = 选中，false = 不选中
        }
    })
</script>
```

**如果要双向绑定（点击复选框也能改变数据），用 v-model**：

```html
<div id="app">
    <input type="checkbox" v-model="checked">
    <p>当前状态：{{checked}}</p>
</div>

<script>
    new Vue({
        el: '#app',
        data: {
            checked: true
        }
    })
</script>
```

**重点**：
- `:checked="变量"` - 单向绑定，只能控制显示
- `v-model="变量"` - 双向绑定，点击也能改变数据
