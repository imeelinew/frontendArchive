# 练习3：商品卡片 - 学习总结

## 📌 练习目标

使用 Vue + AJAX 从远程 API 获取商品数据，并渲染成商品卡片列表。

**API 地址**：`http://shop-api.edu.koobietech.com/prod/tagProdList`

---

## 🧠 核心知识点

### 1. 数据流动过程

```
[远程服务器] ──AJAX请求──> [拿到数据] ──存到Vue──> [data] ──v-for──> [页面显示]
```

### 2. 三步走流程

| 步骤 | 做什么 | 代码位置 |
|-----|-------|---------|
| ① 准备仓库 | 在 `data` 中定义空数组 | `data: { productList: [] }` |
| ② 请求数据 | 在 `mounted()` 中发 AJAX | `mounted() { ajax(...) }` |
| ③ 存储数据 | 把响应数据赋值给数组 | `this.productList = ...` |

### 3. 层层取值规则

```javascript
// 对象用 . 取值
// 数组用 [下标] 取值

result.data[0].productDtoList
//     ↑   ↑   ↑
//    对象 数组 对象
```

---

## ❌ 我踩的坑

### 坑1：变量名不一致

```javascript
// ❌ 错误：data 里定义的是 productList，却存到了 categories
data: { productList: [] }
this.categories = result.data;  // 名字不对！

// ✅ 正确：名字要一致
this.productList = result.data[0].productDtoList;
```

### 坑2：v-for 语法不完整

```html
<!-- ❌ 错误：缺少临时变量 -->
<div v-for="productList">

<!-- ✅ 正确：需要定义 item 变量 -->
<div v-for="item in productList">
```

### 坑3：属性中使用 {{}}

```html
<!-- ❌ 错误：属性里不能用 {{}} -->
<img src="{{item.pic}}">

<!-- ✅ 正确：用 : 绑定（v-bind 简写）-->
<img :src="item.pic">
```

### 坑4：忘记通过 item 访问属性

```html
<!-- ❌ 错误：直接写属性名 -->
<div>{{ prodName }}</div>

<!-- ✅ 正确：通过 item. 访问 -->
<div>{{ item.prodName }}</div>
```

---

## ✅ 最终正确代码

```html
<div id="app">
    <div class="container">
        <div class="item-card" v-for="item in productList">
            <img :src="item.pic" alt="">
            <div>{{ item.prodName }}</div>
            <div>{{ item.brief }}</div>
            <div>¥{{ item.price }}</div>
        </div>
    </div>
</div>

<script>
    new Vue({
        el: '#app',
        data: {
            productList: []
        },
        mounted() {
            ajax('GET', 'http://shop-api.edu.koobietech.com/prod/tagProdList', (res) => {
                let result = JSON.parse(res);
                this.productList = result.data[0].productDtoList;
            })
        }
    })
</script>
```

## 💡 记忆口诀

> **"空仓库，挂载请求，层层取值，循环显示"**

| 口诀 | 含义 |
|-----|------|
| 空仓库 | `data` 里先准备空数组 |
| 挂载请求 | `mounted()` 里发 AJAX |
| 层层取值 | 对象用 `.`，数组用 `[n]` |
| 循环显示 | `v-for="item in list"` |
