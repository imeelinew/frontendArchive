# Vue 组件传参详解（15-17）逐行解读版

---

## 15. 父组件给子组件传数据（父传子）

### 先搞清楚：什么是父组件、什么是子组件？

```
父组件（Vue实例，也就是 new Vue）
    │
    └── 子组件（在 components 里定义的组件）
```

简单说：
- **父组件** = 外面那个大的 Vue 实例
- **子组件** = 在 components 里定义的小组件

---

### 场景：父组件有数据，想让子组件显示

比如父组件有个数字 `i = 10`，想让子组件显示这个 10。

---

### 完整代码逐行讲解

```html
<div id="app">
    <!-- 
        这里是父组件（Vue实例）的地盘
        父组件有数据 i = 10, j = 20
    -->
    
    <!-- 
        使用子组件 <box>
        v-bind:val="i" 的意思是：
        把父组件的 i（值是10）传给子组件
        子组件那边用 val 这个名字接收
        
        可以理解为：val = i = 10
    -->
    <box v-bind:val="i"></box>
    
    <!-- 
        再用一次子组件
        这次传的是 j（值是20）
        所以这个子组件收到的 val = 20
    -->
    <box v-bind:val="j"></box>
</div>
```

```html
<!-- 
    子组件的模板（长什么样）
    写在 app 外面
-->
<template id="box-temp">
    <div>
        <!-- 
            显示 num2
            num2 是子组件自己的数据
            它的初始值来自父组件传过来的 val
        -->
        <h1 @click="addFun">{{num2}}</h1>
    </div>
</template>
```

```html
<script>
    new Vue({
        el: '#app',
        
        // 父组件的数据
        data: {
            i: 10,    // 第一个子组件会收到这个
            j: 20     // 第二个子组件会收到这个
        },
        
        // 定义子组件
        components: {
            "box": {
                // 引用模板
                template: "#box-temp",
                
                // ★★★ 关键点1：用 props 接收父组件传来的数据 ★★★
                // props 是一个数组，里面写要接收的属性名
                // "val" 对应 v-bind:val 里的 val
                props: ["val"],
                
                // 子组件自己的数据
                data() {
                    return {
                        // ★★★ 关键点2：把 props 的值存到自己的 data 里 ★★★
                        // 为什么要这样做？因为 props 的值不能直接改
                        // 所以用 num2 存一份，改 num2 就行
                        // this.val 就是父组件传过来的值
                        num2: this.val
                    }
                },
                
                methods: {
                    addFun() {
                        // 点击时让 num2 加 1
                        // 注意：只能改 num2，不能直接改 this.val
                        this.num2++;
                    }
                }
            }
        }
    })
</script>
```

---

### 数据流向图

```
父组件 data.i = 10
         │
         │  通过 v-bind:val="i" 传递
         ▼
子组件 props.val = 10
         │
         │  在 data() 里复制一份
         ▼
子组件 data.num2 = 10（可以修改这个）
```

---

### 总结

| 步骤 | 在哪写 | 怎么写 |
|------|--------|--------|
| 1. 父组件传数据 | 子组件标签上 | `v-bind:val="i"` 或 `:val="i"` |
| 2. 子组件接收 | 子组件的 props | `props: ["val"]` |
| 3. 存到自己的data | 子组件的 data() | `num2: this.val` |

## 16. 子组件给父组件传数据（子传父）

### 场景：子组件的数据变了，想通知父组件

比如子组件里的数字加了 1，想告诉父组件"我变了，新值是多少"。

---

### 核心思路

子组件不能直接改父组件的数据，只能"喊一声"通知父组件。

就像你不能直接动别人的东西，只能喊一声"帮我改一下"。

这个"喊一声"就是 `$emit`。

---

### 完整代码逐行讲解

```html
<div id="app">
    <div class="box">
        <!-- 
            ★★★ 关键点1：父组件监听子组件的通知 ★★★
            
            v-bind:val="i"  →  传数据给子组件（父传子）
            v-on:child-change="changeFun"  →  监听子组件的通知
            
            意思是：
            当子组件触发 "child-change" 这个事件时，
            执行父组件的 changeFun 方法
        -->
        <box v-bind:val="i" v-on:child-change="changeFun"></box>
        
        <h1>+</h1>
        
        <box v-bind:val="j"></box>
        
        <h1>=</h1>
        
        <!-- 显示两个数的和 -->
        <h1>{{i + j}}</h1>
    </div>
</div>
```

```html
<template id="box-temp">
    <div>
        <!-- 点击时执行 addFun -->
        <h1 @click="addFun">{{num2}}</h1>
    </div>
</template>
```

```html
<script>
    new Vue({
        el: '#app',
        data: {
            i: 10,
            j: 20
        },
        methods: {
            // ★★★ 关键点2：父组件接收子组件通知的方法 ★★★
            // 当子组件 $emit 时，这个方法会被调用
            // a 和 b 是子组件传过来的参数
            changeFun(a, b) {
                console.log("子组件通知我了！");
                console.log("新值是:", a);
                console.log("原值是:", b);
            }
        },
        components: {
            "box": {
                template: "#box-temp",
                props: ["val"],
                data() {
                    return {
                        num2: this.val
                    }
                },
                methods: {
                    addFun() {
                        // 先把自己的值加 1
                        this.num2++;
                        
                        // ★★★ 关键点3：通知父组件 ★★★
                        // this.$emit() 就是"喊一声"
                        // 
                        // 参数1："child-change" 是事件名
                        //        父组件那边用 v-on:child-change 监听
                        //        注意：必须用短横线命名，不能用驼峰！
                        // 
                        // 参数2：this.num2 是要传给父组件的数据（新值）
                        // 参数3：this.val 是原始值
                        // 
                        // 可以传任意多个参数
                        this.$emit("child-change", this.num2, this.val);
                    }
                }
            }
        }
    })
</script>
```

---

### 执行流程

```
1. 用户点击子组件里的 h1

2. 触发子组件的 addFun 方法

3. addFun 里执行 this.num2++（数字加1）

4. addFun 里执行 this.$emit("child-change", this.num2, this.val)
   相当于"喊一声"：嘿！我变了！新值是 xx，原值是 xx

5. 父组件监听到了 "child-change" 事件
   （因为写了 v-on:child-change="changeFun"）

6. 父组件执行 changeFun(a, b)
   a = this.num2（子组件传的第一个参数）
   b = this.val（子组件传的第二个参数）
```

---

### 为什么事件名要用短横线（child-change）而不用驼峰（childChange）？

因为 HTML 不区分大小写！

- 你写 `childChange`，HTML 会变成 `childchange`
- 然后就对不上了

所以必须用短横线命名：`child-change`

---

### 总结

| 步骤 | 在哪写 | 怎么写 |
|------|--------|--------|
| 1. 子组件"喊一声" | 子组件的方法里 | `this.$emit("事件名", 数据1, 数据2)` |
| 2. 父组件监听 | 子组件标签上 | `v-on:事件名="方法"` 或 `@事件名="方法"` |
| 3. 父组件处理 | 父组件的 methods | `方法(参数1, 参数2) { ... }` |

## 17. 动态组件（is 属性）

### 场景：同一个位置，有时显示组件A，有时显示组件B

比如一个标签页：点"首页"显示首页组件，点"关于"显示关于组件。

---

### is 属性是干嘛的？

`is` 可以让任意标签变成指定的组件。

```html
<!-- 这个 div 会变成 box2 组件 -->
<div is="box2"></div>

<!-- 效果等同于直接写 -->
<box2></box2>
```

---

### 完整代码逐行讲解

```html
<div id="app">
    <div>
        <!-- 
            is="box2" 的意思是：
            把这个 div 变成 box2 组件
            
            实际显示的是 box2 组件的内容
        -->
        <div is="box2"></div>
        
        <!-- 
            下面是直接使用组件的写法，效果一样
            但是被注释掉了
        -->
        <!-- <box1></box1> -->
        <!-- <box2></box2> -->
    </div>
</div>
```

```html
<!-- 组件1的模板 -->
<template id="temp1">
    <div>
        <h1>组件一</h1>
    </div>
</template>

<!-- 组件2的模板 -->
<template id="temp2">
    <div>
        <h1>组件二</h1>
    </div>
</template>
```

```html
<script>
    new Vue({
        el: '#app',
        components: {
            // 定义组件1
            "box1": {
                template: "#temp1"
            },
            // 定义组件2
            "box2": {
                template: "#temp2"
            }
        }
    })
</script>
```

---

### 动态切换组件（重点！）

上面的例子是写死的 `is="box2"`，永远显示 box2。

真正有用的是**动态切换**：

```html
<div id="app">
    <!-- 两个按钮，点击切换当前显示的组件 -->
    <button @click="current = 'box1'">显示组件1</button>
    <button @click="current = 'box2'">显示组件2</button>
    
    <!-- 
        :is="current" 是动态绑定
        current 是谁，就显示谁
        
        current = 'box1' 时，显示 box1 组件
        current = 'box2' 时，显示 box2 组件
    -->
    <div :is="current"></div>
</div>

<template id="temp1">
    <div><h1>我是组件一</h1></div>
</template>

<template id="temp2">
    <div><h1>我是组件二</h1></div>
</template>

<script>
    new Vue({
        el: '#app',
        data: {
            // 当前显示哪个组件，默认是 box1
            current: 'box1'
        },
        components: {
            "box1": { template: "#temp1" },
            "box2": { template: "#temp2" }
        }
    })
</script>
```

---

### 执行流程

```
1. 初始状态：current = 'box1'
   页面显示：组件一

2. 用户点击"显示组件2"按钮
   执行：current = 'box2'

3. Vue 检测到 current 变了
   重新渲染 :is="current"
   页面显示：组件二
```

---

### is 属性 vs 直接写组件标签

| 写法 | 示例 | 特点 |
|------|------|------|
| 直接写组件标签 | `<box1></box1>` | 固定显示 box1 |
| is 属性（静态） | `<div is="box1">` | 固定显示 box1 |
| is 属性（动态） | `<div :is="current">` | 根据 current 的值切换显示 |

---

### 总结

| 知识点 | 用法 | 作用 |
|--------|------|------|
| 静态 is | `is="组件名"` | 把标签变成指定组件 |
| 动态 is | `:is="变量"` | 根据变量值切换组件 |

---

## 三个知识点的关系

```
┌─────────────────────────────────────────────────────────┐
│                      父组件                              │
│                                                         │
│   data: { i: 10 }                                      │
│                                                         │
│   ┌───────────────────────────────────────────────┐    │
│   │               子组件                           │    │
│   │                                               │    │
│   │   props: ["val"]  ←──── 15. 父传子（接收数据）│    │
│   │                                               │    │
│   │   $emit("事件名", 数据) ───→ 16. 子传父       │    │
│   │                                               │    │
│   └───────────────────────────────────────────────┘    │
│                                                         │
│   <div :is="current">  ←──── 17. 动态切换组件          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

- **15. 父传子**：父组件有数据，想给子组件用 → 用 props
- **16. 子传父**：子组件有变化，想通知父组件 → 用 $emit
- **17. 动态组件**：同一个位置，切换显示不同组件 → 用 :is
